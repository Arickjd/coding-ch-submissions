## Ownership rules

| Location                                                                     | Owner         | Rule                                                                         |
| :--------------------------------------------------------------------------- | :------------ | :--------------------------------------------------------------------------- |
| Top-level topic folders created by NeetCode (for example,`Design Patterns/`) | NeetCode Sync | Do not rename, move, or manually add files here.                             |
| `_manual/leetcode/`                                                          | Manual        | Add LeetCode solutions only here.                                            |
| `_manual/kaggle/` and `_manual/other-platforms/`                             | Manual        | Add non-NeetCode work only here.                                             |
| `README.md`                                                                  | Manual        | Update the dashboard after manual additions; keep the auto-sync note intact. |

The `_manual` prefix creates a separate namespace. This is the key convention that prevents a manually uploaded solution from colliding with a file path generated by NeetCode.

## Adding a solution manually

1. Choose the platform folder under `_manual/`.
2. Use the platform difficulty when it exists (`easy`, `medium`, or `hard`). Otherwise use `unclassified`.
3. Create one directory per problem using a stable, searchable name: `<id>-<problem-slug>` (for example, `0001-two-sum`).
4. Add the solution as `solution.<extension>`. Optional notes or complexity analysis can live in `README.md` next to it.
5. Update the three dashboard tables above.

Example:

```text
_manual/leetcode/easy/0001-two-sum/solution.py
_manual/other-platforms/hackerrank/easy/solve-me-first/solution.js
```

## NeetCode synchronization

NeetCode GitHub Sync owns the submission directories it creates and pushes new submissions to this repository automatically. Manage its settings, including status filter, auto-commit, and bulk sync, at [NeetCode GitHub settings](https://neetcode.io/profile/github).

## Languages

Solutions may be written in any platform-supported language. Common extensions include `.py`, `.cpp`, `.go`, `.rs`, and `.sql`.
